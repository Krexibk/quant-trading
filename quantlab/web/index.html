🔒
What this form will and will not accept. Enter only the last four digits of an account — the server rejects a full account number, routing number or card number outright. That is not a limitation to work around: handling those puts you in PCI-DSS and banking-regulation scope, and a local SQLite file is not a safe place for them. To move real money, implement a provider against Plaid (bank links), Stripe (cards/ACH) or Alpaca (brokerage) — see quantlab/banking/providers.py. Those services hold the credentials; your server only ever sees an opaque token.
